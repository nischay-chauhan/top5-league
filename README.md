# ⚽ Football Stats Explorer - Top 5 Leagues

A modern, interactive web application built with Streamlit to explore and analyze football player statistics from the top 5 European leagues for the 2023/24 season.

## 🌟 Features

- **Interactive Player Search**: Easily search and select players from the top 5 leagues
- **Advanced Filtering**: Filter players by league and position
- **Comprehensive Statistics**: View detailed player statistics including:
  - Goals and Assists
  - Expected Goals (xG) and Expected Assists (xAG)
  - Per 90 minutes metrics
  - Match participation data
- **Dynamic Visualizations**: Multiple chart types to visualize player statistics:
  - Bar Charts
  - Pie Charts
  - Line Charts
  - Radar Charts
- **Player Comparison**: Head-to-head comparison of statistics between any two players
- **Customizable Display**: Choose different color themes for visualizations
- **Responsive Design**: Beautiful and modern UI that works on all screen sizes

## 🚀 Getting Started

### Prerequisites

- Python 3.7+
- pip (Python package manager)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/football-stats-explorer.git
cd football-stats-explorer
```

2. Create a virtual environment (optional but recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

3. Install the required packages:
```bash
pip install -r requirements.txt
```

### Running the Application

1. Start the Streamlit server:
```bash
streamlit run main.py
```

2. Open your web browser and navigate to `http://localhost:8501`

## 📊 Data Source

The application uses player statistics data from the top 5 European leagues for the 2023/24 season. The data includes:
- English Premier League
- Spanish La Liga
- German Bundesliga
- Italian Serie A
- French Ligue 1
